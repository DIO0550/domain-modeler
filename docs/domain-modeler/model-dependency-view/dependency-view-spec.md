# モデル依存図 — 画面仕様（FE）

機能: [概要](./index.md) / 状態: レビュー用ドラフト

## 責務

解析済みのモデルを図として表示し、参照関係をたどる操作を提供する。構文解析や参照先の推測を画面内で行わない。宣言種別と参照の意味は[グラフ生成仕様](./model-graph-spec.md)に従う。

## 画面の位置付け

- 文書全体の「モデル／ステートマシン」切替は維持する。
- 「モデル」の中に「定義＋プレビュー／依存図」の切替を追加する。
- 依存図ではキャンバスを広く使い、右側に選択対象のインスペクターを置く。
- 定義エディタを常時併設しない。確認はインスペクター、編集は「定義を編集」から既存画面へ移動する。
- 新しいトップレベルの文書種別やファイル拡張子は作らない。

## レイアウトと操作部品

| 領域 | 内容 | 動作 |
| --- | --- | --- |
| 既存ヘッダー | 文書名、既存操作、文書モード切替 | 既存の責務を維持 |
| 表示切替 | 定義＋プレビュー／依存図 | 本文を変えず表示を切り替える |
| 図のツールバー | 全体／関連のみ、ズーム、全体に合わせる、再配置 | 現在の図だけに作用 |
| 中央 | ノードと矢印 | ノード選択、パン、ズーム |
| インスペクター | 名前、種別、依存先、参照元、定義、診断 | 関連先の選択、定義編集へ移動 |

文書名やUndo/Redoを図のツールバーに重複配置しない。検索・複数段のフィルター・常設のAIチャットは初期スコープに追加しない。

## ノード表示

| 宣言の形 | ラベル | 表示内容 |
| --- | --- | --- |
| AND | RECORD | 名前、構成要素を縦に並べ、ANDの結合を明示 |
| OR | CHOICE | 名前、各候補とOR表記。継承記号は使用しない |
| 単一参照 | ALIAS | 名前、参照先またはプリミティブ型 |
| 制約付き | VALUE | 名前、プリミティブ型、範囲・長さ制約 |
| workflow | WORKFLOW | 名前、入力、出力、エラーの行。未指定のエラー行は省略 |
| 未定義参照 | 未定義 | 名前と警告。通常の宣言として扱わない |

- `list`・`option` は参照する項目に付ける。重なった修飾の順序も保持する。
- 名前は読み取れることを優先して折り返す。長い定義の全文はインスペクターでも確認できる。
- プリミティブ型はカード内に表示し、専用ノードを作らない。
- ノード寸法は内容に合わせる。文字を一律に縮小して収めない。

## 矢印と選択

- 矢印は常に「参照する宣言 → 参照される宣言」。図内に凡例を表示する。
- workflow の関係には「入力」「出力」「エラー」を表示する。入力でも向きを反転しない。
- data の関係は「構成要素」「選択肢」「別名」を必要に応じて表示する。
- 同じ2宣言間に複数の役割がある場合は、1本の線に複数ラベルを表示し、詳細には各参照を列挙する。
- 選択したノードと、そこに接続する両方向の線・ノードを強調する。それ以外も全体表示では読めるコントラストを維持する。
- 依存先と参照元の区別は矢印方向とインスペクターの見出しで伝える。
- 空白部分をクリックすると選択を解除する。線の選択・編集は初期スコープ外。

## 関連のみ表示

1. ノード選択中に「関連のみ」を選ぶ。
2. 選択ノード、直接の依存先、直接の参照元を表示する。
3. 線は選択ノードに直接接続するものだけを表示する。近傍同士の線は追加しない。
4. 別のノードを選ぶと、そのノードを中心とする直接近傍に更新する。
5. 「全体」に戻すと、選択を維持して全文書のグラフを表示する。

未選択時は「関連のみ」を無効にする。関連のみ表示中に選択解除・対象削除が起きた場合は全体へ戻す。直接近傍を変更すると表示対象へフィットし、全体へ戻した場合は切替前の全体表示のパン・ズームへ復帰する。

この操作は推移的な影響分析ではない。直接の参照元のさらに参照元は自動展開しない。

## インスペクター

| 項目 | 表示・動作 |
| --- | --- |
| 選択なし | 「モデルを選択すると定義と参照関係を確認できます」 |
| 名前・種別 | 選択ノードの宣言名と分類 |
| 依存先 | 一意の対象ごとに表示。workflowでは入力・出力・エラーの役割も表示 |
| 参照元 | 一意の宣言ごとに表示。どの役割から参照されるかも表示 |
| 定義 | 現在の本文から該当範囲を読み取り専用で表示 |
| 定義を編集 | 「定義＋プレビュー」に切り替え、該当範囲へ移動してエディタにフォーカス |
| 診断 | 既存解析結果の警告・エラー。参照箇所へ移動可能 |

参照先・参照元の項目を押すと図内のそのノードを選択し、見える位置へ移動する。該当項目がなければ「なし」を表示する。

未定義ノードには定義本文と「定義を編集」を表示しない。「定義がありません」と参照元一覧を表示し、各参照箇所へ移動できる。既存のスタブ生成への新しい入口は追加しない。

## パン・ズーム・配置

- 空白のドラッグでパンする。ノードのドラッグ移動は行わない。
- 拡大・縮小ボタンと倍率を表示し、トラックパッド等の操作は既存アプリの方針に合わせる。
- 「全体に合わせる」は現在の表示対象が収まる倍率・位置へ変更する。ノード位置は変えない。
- 「再配置」は全文書のノード配置を再計算して現在の表示対象へフィットする。
- 初回表示では自動配置後に全体へフィットする。更新時の扱いは[文書同期仕様](./document-sync-spec.md)に従う。

## 空・異常状態

| 状態 | 表示と復旧 |
| --- | --- |
| 空文書／state-machineのみ | 「表示できるdata・workflowがありません」。定義画面へ戻れる |
| 宣言が孤立している | 矢印なしでノードを表示。「参照なし」は正常 |
| 一部の宣言に構文エラー | 正常な宣言は表示し、診断領域から該当行へ移動できる |
| 未定義参照 | 未定義ノードと警告。通常の参照線と区別する |
| 循環・自己参照 | 線を表示する。循環であることだけを理由にエラーにはしない |
| 図生成・配置に失敗 | 図のエラーを表示し、再試行と定義画面への移動を提供。本文編集・保存を妨げない |

## アクセシビリティと狭いウインドウ

- 表示切替・ツールバー・ノード・参照一覧・編集移動をキーボードで操作できる。
- ノードの読み上げ名に宣言名と種類を含める。選択状態を伝える。
- 色に加えてラベル・矢印・選択枠・警告文を使う。
- 狭い場合はツールバーを折り返し、インスペクターを下部に移す。図はパン・ズームで閲覧する。
- 横並びのカードを文字ごと縮小しただけの表示にしない。
- 定義へ移動後はエディタにフォーカスし、再び図へ戻る操作をキーボードで行える。

## 受入条件

| ID | 操作・条件 | 期待結果 |
| --- | --- | --- |
| UI-01 | 注文を選択 | 注文の依存先・参照元と接続線が強調される |
| UI-02 | workflowを選択 | 入力・出力・エラーの違いが文字でも分かる |
| UI-03 | 関連のみ→別ノード選択 | 新しい選択の直接近傍だけに更新される |
| UI-04 | 全体に戻す | 全ノードと線が復帰し、選択が維持される |
| UI-05 | 定義を編集 | 正しい宣言位置へ移動する |
| UI-06 | 未定義ノードを選択 | 架空の本文を表示せず参照元へ移動できる |
| UI-07 | キーボード操作 | 図の選択・関連表示・定義移動が完了できる |
| UI-08 | 狭いウインドウ | 操作部品と詳細が重ならず、本文の全文を確認できる |
