## 1. 責務と非責務

### 責務

- 付箋・接続線・ビューポートの描画
- ポインタ・キーボード入力の解釈と、canvas-core 操作への変換
- 種別ごとの色・標準サイズの定義
- ソフト警告(接続ルール外)の視覚表現

### 非責務

- ドキュメントの変更・不変条件・履歴(canvas-core)
- 座標変換・ヒットテスト・自動アンカーの計算(canvas-core。UIは結果を使うだけ)
- 保存・ファイル監視(technical.md)、通知(app-shell)

## 2. 画面構成

- 上部: 種別パレット(付箋8種)と undo / redo
- 残り全面: キャンバス。スクロールバーは持たず、パン・ズームのみで移動する
- 付箋の描画はDOM要素で行う(テキスト編集が主役のため。SVG / Canvas 2D は採用しない)。接続線のみSVGレイヤーに描く

## 3. 付箋の表示

### 3.1 種別ごとの色と標準サイズ

色は物理付箋の慣習に従う。具体的な色値はテーマの裁量とし、系統のみ規定する:

| 種別 | 色系統 | 標準サイズ(ワールド座標) |
| --- | --- | --- |
| Domain Event | オレンジ | 160 × 100 |
| Command | 青 | 160 × 100 |
| Actor | 黄(小) | 120 × 80 |
| Aggregate | 黄(大) | 200 × 140 |
| Policy | 紫 | 160 × 100 |
| Read Model | 緑 | 160 × 100 |
| External System | ピンク | 160 × 100 |
| Hotspot | 赤 | 140 × 100。慣習に倣い僅かに傾けて描画する(傾きは表示のみ。座標・サイズは他と同じ矩形として扱う) |

- 標準サイズは新規作成時に書き込む初期値であり、以後はファイルの `size` が真実(リサイズ自由)
- 付箋には種別名を小さくキャプション表示する(色だけに頼らない)

### 3.2 本文の表示

- 本文は付箋の中央に表示し、折り返す
- あふれる場合は付箋からはみ出さずに末尾を省略する(自動でサイズは変えない。広げるかはユーザーの判断)

## 4. 付箋の操作

| 操作 | 入力 | 挙動 |
| --- | --- | --- |
| 作成 | パレットで種別を選びキャンバスをクリック | クリック位置に標準サイズで作成し、即座に本文編集を開始する |
| 作成(近道) | 空白部のダブルクリック | 最後に使った種別で作成する |
| 選択 | クリック | 単一選択。選択枠とリサイズハンドルを表示する |
| 本文編集 | ダブルクリック | インライン編集。フォーカスアウトか Esc で確定する(編集セッションが履歴1エントリ) |
| 移動 | ドラッグ | ドラッグ開始時に前面化する(物理付箋を持ち上げる動きに対応)。グリッドスナップはしない |
| リサイズ | 選択中の四隅ハンドルをドラッグ | 最小サイズ(60 × 40)を下回れない |
| 種別変更 | 選択中に表示されるミニツールバーから | 色・キャプションが変わる。サイズは変えない |
| 削除 | 選択中に Delete / Backspace | 参照する接続も消える(canvas-core のカスケード) |

移動・リサイズはトランザクション(ドラッグ開始〜離す)で1履歴エントリとする。

## 5. 接続線の表示

### 5.1 形状

- 始点・終点は canvas-core が解決したアンカー位置(付箋の辺の中点)とする
- 両アンカーが同じ軸で向かい合い、ほぼ水平・垂直に結べる場合は直線。それ以外は三次ベジェ曲線(制御点は各アンカーの辺の法線方向へ出す)
- 終端に矢印を描く

### 5.2 ラベル

- 線の中点付近に配置し、背景チップを敷いて線と重なっても読めるようにする
- 空文字のラベルは表示しない

### 5.3 ソフト警告の表現

- canvas-core の判定が「警告」の接続は、点線 + 警告色で描く
- ホバーでルール外である旨と期待される接続(例: Policy から引けるのは Command)をツールチップ表示する
- 警告は情報提供であり、操作は一切妨げない

## 6. 接続の操作

| 操作 | 入力 | 挙動 |
| --- | --- | --- |
| 作成 | 付箋のホバー時に外周へ表示される接続ハンドルを相手の付箋までドラッグ | アンカー未指定(自動)で作成する |
| 選択 | 線のクリック(許容距離は canvas-core の規定) | 端点ハンドルとラベルを強調する |
| ラベル編集 | 線のダブルクリック | インライン編集 |
| アンカーの明示指定 | 選択中の端点ハンドルを付箋の辺へドラッグ | その辺に固定する(ファイルに保存される)。付箋の外へドラッグした場合は自動に戻す |
| 削除 | 選択中に Delete / Backspace | 接続のみ削除する |

## 7. ビューポート操作

| 操作 | 入力 |
| --- | --- |
| パン | 空白部のドラッグ、またはホイール / 2本指スクロール |
| ズーム | ピンチ、または Cmd(Ctrl)+ホイール。カーソル位置を不動点とする(canvas-core) |
| 全体表示 | ショートカット(下表)で全付箋が収まる位置とズームに移動する |

## 8. キーボードショートカット

| キー | 動作 |
| --- | --- |
| Cmd(Ctrl)+Z / Shift+Cmd(Ctrl)+Z | undo / redo |
| Delete / Backspace | 選択対象の削除 |
| Esc | 編集の確定・選択解除 |
| Cmd(Ctrl)+0 | 全体表示 |
| Cmd(Ctrl)+= / Cmd(Ctrl)+- | 段階ズームイン / アウト(中心固定) |

テキスト編集中はショートカットを編集操作に譲る。

## 9. 外部変更の反映

- 外部(AI・エディタ)からの取り込み(canvas-core 10)が起きたら描画を新しいドキュメントに差し替える
- 選択中の要素が取り込み後も存在すれば選択を維持し、消えていれば選択解除する
- 取り込みの通知(トースト等)は app-shell の責務

## 10. スコープ外

- 複数選択・矩形選択・整列・分配・グリッドスナップ(canvas-core と同じく将来判断)
- 付箋のグループ枠(Bounded Context囲い)
- ミニマップ、キャンバスの画像エクスポート
- テーマの具体色値の規定(実装時にライト / ダーク両テーマを設計する際に決める)
