# ステートマシンのキャンバス配置

対象: #291 の配置 (#292)、接続 (#262)、図上の名前編集 (#293)。Delete等は #263、パン・ホイールズームは #264、初期／終端の表示改善は #266。

## 操作

- 左の「状態」を選び、キャンバスをクリックして状態を1個配置する。初期名は未使用の `状態1`、`状態2` …。未定義参照と同じ名前も避ける。
- 状態も初期指定もないマシンでは、最初のクリック配置を初期状態にする。
- 配置後は新しい状態を選択する。右のプロパティから名前・初期／終端属性を編集できる。既存フォームによる追加も利用できる。
- 状態をドラッグして移動する。4px未満の手ぶれはクリックとし、判定距離は倍率によらない画面座標で測る。一度閾値を超えれば開始点へ戻ってもドラッグとして扱う。
- ドラッグ中は状態と遷移線の表示のみを更新し、確定時に全文を1回更新する。
- Escape / pointercancel は取消。lostpointercapture だけが起きた場合は最後の表示位置を1回確定する。pointerup後の捕捉解除では再確定しない。
- 通常の空白クリックは選択解除。「選択」またはEscapeで配置待ちを解除する。既存状態・遷移の選択でも配置待ちを解除する。
- 配置待ちの空白ドラッグでは追加しない。次の通常クリックでは配置できる。
- 未解決参照と重複した状態は移動しない。編集中のエラーは既存の診断表示に残す。
- 負の座標にも配置・移動できる。フィットは負方向も含めて全体を表示する。

## 文書と保存形式

```text
state-machine 注文 =
  initial: 未払い
  state: 未払い // 支払い待ち @canvas-position(v1, 240, 160)
  state: 支払済み terminal // @canvas-position(v1, 560, 320)
  transition: 未払い -> 支払済み on 支払い完了
```

予約コメント `@canvas-position(v1, x, y)` は状態宣言と同じ行の末尾に置く。`x` / `y` はSVG上の中心座標で、-1000000〜1000000の有限数、保存時は小数点以下2桁へ丸める。通常コメントがあれば末尾に追加する。LF / CRLFを維持する。

座標は名前をキーにした別文書へ保存せず、宣言行そのものに属する。GUIのリネーム・初期／終端属性変更は既存のコメント保持処理を通り、同じ行の座標を維持する。DSL直接編集でも宣言行のコメントが残れば復元する。状態削除ではその行と座標が一緒に消える。マシン名変更や、別マシンの同名状態に影響されない。

- コメントなしの旧文書: 従来の自動配置。閲覧だけでは書き換えない。
- 最初の配置・移動・接続: マシン内の実在する状態の現在位置も保存して、その後の内容編集から位置を独立させる。
- 保存済み座標がある文書へDSLやフォームから追加した未注釈の状態: 保存済み状態の右側へ導出配置する。既存座標は動かさない。未注釈の状態同士は手動配置が確定するまで自動配置となる。
- 未解決参照: 描画位置だけを導出し、存在しない状態宣言の座標コメントは作らない。
- 不正なコメント・未対応バージョン: エラーを画面へ表示する。グラフは自動配置で参照可能だが、配置・移動・整列による上書きを拒否する。モデル定義で修正する。
- 旧バージョンのアプリ: コメントを無視して従来の自動配置で表示する。コメントを保持する編集では座標情報も残る。

`.dmodel` 全文を既存の `ModelTextHistory` と自動保存へ渡すため、配置とDSLは1ファイル・1履歴・1回のアトミック書き込みになる。モード切替でキャンバスが再生成されても、保存・再読込しても同じコメントから復元する。書き込みや外部変更の競合処理は既存の文書セッションへ委ねる。ドラッグ開始後に全文が変わった場合は古いドラッグ結果を確定しない。

## 表示範囲と自動整列

座標と表示範囲は別の値とする。ドラッグ・状態追加のたびにviewBoxを再計算すると、ポインターの下で図全体が動くため、表示範囲はマシンを開いた時点で固定する。

- 「フィット」は現在の全体範囲と倍率を更新し、文書・座標・履歴を変更しない。小さい図には配置用の余白を残す。
- 「自動整列」は全状態を従来の配置規則で並べ直し、座標コメントを1回更新する。Undoで以前の手動配置へ戻せる。
- マシン切替で表示範囲と一時操作を初期化する。
- パン・ホイールズームは #264 で追加し、画面→SVG座標変換と操作判定を共有する。

## 責務と検証

`StateMachinePosition` は座標と予約コメント、`StateMachinePlacement` は宣言と配置の対応、`StateMachineLayout` は配置・遷移経路、`StateMachineGesture` はドラッグ判定を担当する。全文更新は `StateMachineSource`、操作の仲介は `useStateMachineCanvas`、SVGのDOM操作は `libs/svg-canvas` に置く。新しい外部ランタイム依存は追加しない。

自動テストでは旧形式・コメント保持・CRLF・別マシン・名前変更・属性変更・削除・不正コメント、クリックとドラッグの区別、取消と捕捉喪失、外部更新、文書セッション経由の自動保存・モード切替・Undo/Redo・再読込を検証する。DOM行列とファイルI/Oのみテスト用実装を使う。

`rules/ui-verification.md` に従い、マージ前には1280×720以上の実画面で、配置→移動→編集→Undo/Redo→再読込を確認する。倍率変更後、キャンバス外でのリリース、ライト／ダーク、連続キーボード操作も確認する。

## ハンドルから遷移を作成する (#262)

- 一意な非終端状態を選ぶと四辺中央にハンドルを表示する。未定義参照・重複宣言・終端状態から接続は開始できない。
- ハンドルから状態へドラッグすると仮線を表示し、実在する一意な候補だけを強調する。重なる状態は描画順の最前面を候補とする。終点は候補の四辺中央のうちポインターに最も近い点へ付ける。
- ドロップ時も同じヒット判定を行い、線付近にイベント入力を開いてフォーカスする。自分自身へのドロップでは自己ループを作成できる。4px未満の手ぶれでは入力を開かない。
- イベント名を入力してEnterまたは「確定」で遷移を追加する。空欄・不正な識別子・重複遷移は入力欄へエラーを表示し、文書を変更しない。IME変換中のEnterでは確定しない。
- 空白へのドロップ、Escape、pointercancel、接続中の捕捉喪失は取消。入力中はEscapeまたは「取消」で破棄する。取消後のclick/dblclickや通常の空白クリックでは状態を配置しない。
- 別の選択・マシンへの切替では接続下書きを持ち越さない。操作開始後の文書変更があれば古い接続を確定しない。
- 接続確定時に現在の状態座標と遷移を1回で全文へ反映する。未注釈の旧文書でも接続によって状態が自動再配置されない。未確定入力は保存せず、確定後は既存のUndo/Redo・自動保存へ接続する。

候補判定・ハンドル座標・仮線は `StateMachineConnection`、文書更新は `StateMachineSource.connect` が担当する。図上の入力部品 `GraphLabelInput` は、表示位置・初期値・確定と取消の操作を受け取り、後続 #293 の名前編集でも利用できる。

## 図上で状態名・イベント名を編集する (#293)

- 状態をダブルクリックすると、その位置に現在の名前を選択した入力欄を開く。既存の遷移は線やイベントラベルのダブルクリックで、線付近にイベント名の入力を開く。
- 接続直後のイベント入力と同じ `GraphLabelInput` を使う。Enter／「確定」で反映、Escape／「取消」で破棄する。IME変換中のEnter／Escapeでは編集を終了しない。
- 確定・取消ボタンや右プロパティへフォーカスを移しただけでは保存しない。入力欄の値を保持し、別要素・空白のクリックやマシン切替では破棄する。右プロパティの編集が確定した場合も、その文書更新で図上の下書きを破棄する。
- 重複した状態名、空欄、不正な識別子、重複遷移、終端状態からの遷移は既存の `StateMachineSource.updateState`／`updateTransition` で検証する。失敗時は入力を保持してエラーを表示する。未定義参照・重複宣言の状態には図上の状態名入力を開かない。
- 状態名の変更では初期指定、入出遷移、自己ループの参照を一括更新する。初期／終端属性、コメント、改行形式と保存済み座標は維持する。座標コメントのない旧文書でも現在位置を記録して、名前の並び替えで状態が移動しないようにする。
- 名前の確定は1回の全文更新で、既存の自動保存・Undo/Redoへ渡す。変更のない名前確定と取消では文書・履歴を変更しない。
- ドラッグ・接続・取消の直後に届くclick/dblclickでは編集を起動しない。新しく始めた通常のダブルクリックでは編集できる。判定はブラウザーのクリック回数と完了したポインター操作を使い、固定時間のタイマーは使わない。
- 入力中に文書が変更された場合は下書きを破棄する。Undo/Redoで同じ全文に戻っても、破棄済みの下書きを再表示しない。確定・取消後はグラフへフォーカスを戻し、連続してキーボード操作できる。

`StateMachineLabelEdit` が初期値・編集位置・確定後の選択を担当し、`StateMachineActivation` がポインター後の誤起動を防ぐ。全文更新の入口は `StateMachineSource.rename` とする。

## 選択解除とキーボード削除 (#263)

- 空白の通常クリックで選択を解除する。Escapeで選択と配置待ちを解除し、移動・接続中は仮操作を取り消す。図上入力のEscapeは下書きの取消として扱う。
- グラフまたはその状態・遷移にフォーカスがあるとき、修飾キーなしのDelete／Backspaceで選択中の要素を削除する。状態は初期参照・入出遷移・自己遷移も同時に削除し、他の状態の座標や別マシンは保持する。
- 入力・textarea・select・contenteditable内のキーとIME変換中のキーはグラフで処理しない。右プロパティやツールバーのボタン上でDeleteを押しても削除しない。移動・接続・図上入力が進行中の場合も削除を確定しない。
- インスペクターとキーボードの削除は同じ `StateMachineSource.removeSelection` から既存の全文更新を利用し、1履歴として自動保存する。未定義参照・重複状態・消えた選択対象はエラーとし、他の要素を削除しない。
- 削除後・グラフでのEscape後はグラフにフォーカスを残し、Undo／Redoを連続して入力できる。Undoでフォーカス中の状態が消えた場合もグラフへ戻す。遅延したフォーカス復帰は別画面の操作を奪わない。
- Enter／Spaceによる状態・遷移の選択は引き続き利用できる。
