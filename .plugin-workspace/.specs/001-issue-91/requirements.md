# Requirements: エラー回復パーサー
## ユースケース
### UC-1: 壊れた編集中文書を継続解析する
- **アクター**: model-core利用者
- **状況/前提**: 正常宣言と複数の不正宣言が混在する
- **達成したいこと**: 一つのエラーで停止せず後続宣言も解析する
- **成功条件**: 正常宣言を含むASTと複数diagnosticsを一度に返す
### UC-2: 末尾の不正宣言を扱う
- **アクター**: model-core利用者
- **状況/前提**: 最終宣言が不正である
- **達成したいこと**: 停止せず解析結果を得る
- **成功条件**: ErrorDeclとdiagnosticを返す
## 要件・制約
### 機能要件
- 宣言先頭のdata/workflowを同期点に解析を継続する。
- diagnosticsを入力順で返し、正常宣言もASTに保持する。
- 不正宣言はErrorDeclとして位置を保持する。
### 非機能要件
- 外部依存を追加せず、線形解析特性と既存テストを維持する。
### 制約・設計方針
- 既存実装を再利用し、専用回帰テストで完了条件を固定する。
## 未解決の確認事項
■ ユーザー確認により、既存公開契約どおりErrorDeclを維持する。
