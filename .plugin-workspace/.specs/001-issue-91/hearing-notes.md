# Hearing Notes: エラー回復パーサー
## 目的
不正なトップレベル宣言があっても次の宣言境界から解析を再開し、ASTと複数diagnosticsを同時に返す。
## スコープ
- **種別**: 既存機能の改善
- **影響範囲**: `packages/model-core` のパーサーテスト
- **優先度**: 高
## 技術的詳細
- **技術スタック**: TypeScript strict mode / Vitest
- **依存関係**: 既存Tokenizer、AST、Diagnosticのみ
- **データ構造**: 不正宣言は既存契約どおりErrorDeclとして保持する
## 品質要件
- **エッジケース**: 複数不正宣言、前後の正常宣言、末尾エラー、進捗保証
- **テスト要件**: 公開APIの回帰テスト
- **パフォーマンス**: 既存の線形特性を維持する
